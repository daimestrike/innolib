# Библиотека инноваций — вики проекта

Здесь собрано всё, что нужно знать о проекте: зачем он появился, как им пользоваться, как он устроен внутри и как его развернуть у себя. Документы можно читать по порядку, а можно сразу открыть нужный.

Каждый файл самостоятельный. Его можно целиком перенести в корпоративную вики (Confluence и т. п.) как отдельную страницу. Схемы нарисованы в Mermaid: GitHub показывает их как картинки, а в Confluence их можно вставить через макрос Mermaid или заменить скриншотом.

## Коротко о главном

**Библиотека инноваций** — это общий реестр инновационных проектов и идей с ИИ-помощником. В одном месте видно, что уже сделали, что сейчас в пилоте и что только задумано. Новый кейс заводится за пару минут через короткий опрос. Консультант подсказывает, было ли уже что-то похожее, а генератор предлагает новые идеи с опорой на существующий опыт.

Систему можно развернуть внутри закрытого контура без доступа в интернет. Сервер написан на чистом Python, база хранится в одном файле SQLite, а модель подключается через любой OpenAI-совместимый шлюз.

- Исходный код и релизы: [github.com/daimestrike/innolib](https://github.com/daimestrike/innolib)
- Текущая версия: см. файл `VERSION` в корне репозитория и [CHANGELOG](../CHANGELOG.md)
