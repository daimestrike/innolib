# Изменения

Формат версий — [SemVer](https://semver.org/lang/ru/): MAJOR.MINOR.PATCH.

## [1.1.0] — 2026-09-29

- Консультант по инновациям: вкладка с чатом, ответ потоком, ссылки на кейсы `[INN-…]` и документы `[DOC-…]` с переходом в карточку.
- RAG: поиск BM25 со стеммингом для русского по реестру и базе знаний; каталог и сводка реестра в контексте модели; опциональный гибридный поиск с эмбеддингами (`EMBED_MODEL`).
- База знаний: загрузка TXT, MD, CSV, HTML, DOCX из интерфейса и командой `add-doc`.
- «Оформить идею в карточку»: мастер собирает карточку из диалога с консультантом.
- Клиент LLM вынесен в `llm.py`: потоковые ответы, вырезание `<think>` у reasoning-моделей, `LLM_EXTRA_JSON`, `LLM_CHAT_MODEL`, `LLM_USE_SYSTEM_PROXY`.
- Команды `check-llm` (проверка подключения) и `reindex`; `.env` подхватывается и без Docker.

## [1.0.0] — 2026-09-28

Первая версия для развёртывания в закрытом контуре.

- Реестр проектов и идей: карточки, воронка стадий (идея → проработка → пилот → внедрено / остановлено), поиск и фильтры.
- Мастер добавления кейса: 4 вопроса в формате диалога или вставка текста страницы вики.
- Разбор ответов через внутреннюю LLM (OpenAI-совместимый API); без LLM мастер работает в упрощённом режиме.
- Подсказка похожих проектов и предупреждение о возможном дубле.
- Импорт кейсов из CSV/JSON, выгрузка в CSV (Excel) и JSON.
- Сервер на стандартной библиотеке Python, база SQLite, шрифты внутри — интернет не нужен.
- Docker, docker-compose, systemd, пример nginx; `build_offline.sh` для переноса в контур.
